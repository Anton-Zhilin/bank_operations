# Приложение для анализа банковских операций

## Описание проекта

Это приложение на Python для анализа транзакций, которые находятся в Excel-файле. 
Приложение генерирует JSON-данные для веб-страниц, формирует Excel-отчеты, а также предоставляет другие сервисы.

Проект создан и управляется с помощью **Poetry**, конфигурация описана в файле `pyproject.toml`.

---

## Установка

1. Убедитесь, что у вас установлен Python 3.8+ и Poetry
2. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:Anton-Zhilin/bank_operations.git
3. Установите зависимости с помощью Poetry:
   ```bash

## Структура проекта

Проект состоит из 5 основных модулей, каждый из которых отвечает за свою зону ответственности:

```text
src/
├── main.py        
├── reports.py
├── services.py
├── utils.py 
└── views.py  
```

### 1. Модуль main
Главная функция, принимающую на вход строку с датой и временем в формате YYYY-MM-DD HH:MM:SS и возвращающую JSON-ответ со следующими данными:
Блок приветствия в зависимости от времени суток
По каждой карте:
последние 4 цифры карты;
общая сумма расходов;
кешбэк (1 рубль на каждые 100 рублей).
Топ-5 транзакций по сумме платежа.
Курс валют.
Стоимость акций из S&P500.

### 2. Модуль reports
Модуль для отчётов по транзакциям
Содержит декоратор для функций-отчетов. Записывает в файл результат, который возвращает функция, формирующая отчет.

Декоратор без параметра — записывает данные отчета в файл с названием по умолчанию (формат имени файла придумайте самостоятельно).
Декоратор с параметром — принимает имя файла в качестве параметра.

Функции:
Траты по категории
Траты по дням недели
Траты в рабочий/выходной день

### 3. Модуль services
Функции сервисов:
Выгодные категории повышенного кешбэка - Сервис позволяет проанализировать, какие категории были наиболее выгодными для выбора в качестве категорий повышенного кешбэка.
Инвесткопилка - Позволяет копить через округление ваших трат.
Простой поиск - Пользователь передает строку для поиска, возвращается JSON-ответ со всеми транзакциями, содержащими запрос в описании или категории.
Поиск по телефонным номерам - Функция возвращает JSON со всеми транзакциями, содержащими в описании мобильные номера.

### 4. Модуль utils
Содержит вспомогательные функции для работы приложения

### 5. Модуль views
Здесь реализованы основные функции для генерации JSON-ответов
Функция приветствия, которая в зависимости от текущего времени суток нужно возвращать одно из четырех приветствий: «Доброе утро», «Добрый день», «Добрый вечер», «Доброй ночи».
Функция, возвращая актуальные курсы валют
Функция, которая возвращает актуальные курсы акций

Содержит функцию, реализующая страницу приложения "События"
Она принимающую на вход строку с датой и второй необязательный параметр — диапазон данных. По умолчанию диапазон равен одному месяцу (с начала месяца, на который выпадает дата, по саму дату).
Возможные значения второго необязательного параметра:
W — неделя, на которую приходится дата;
M — месяц, на который приходится дата;
Y — год, на который приходится дата;
ALL — все данные до указанной даты.
Возвращаемый JSON-ответ содержит следующие данные:
«Расходы»:
Общая сумма расходов.
Раздел «Основные», в котором траты по категориям отсортированы по убыванию. Данные предоставляются по 7 категориям с наибольшими тратами, траты по остальным категориям суммируются и попадают в категорию «Остальное».
Раздел «Переводы и наличные», в котором сумма по категориям «Наличные» и «Переводы» отсортирована по убыванию.
«Поступления»:
Общая сумма поступлений.
Раздел «Основные», в котором поступления по категориям отсортированы по убыванию.
Курс валют.
Стоимость акций из S&P 500.

### Модуль run в корне проекта
Вспомогательный тестовый модуль, показывающий пример работы функции main и функций модуля reports - показывает выводимые отчёты
